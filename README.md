# Multi-ship COLREGS collision avoidance (thesis)

Partial code from an undergraduate final-year project: **COLREGS-compliant multi-ship collision avoidance** using **deep reinforcement learning**.

## Goal

Train ship agents to avoid collisions with other vessels while following COLREGS (rules of the road).

## Environment

Custom-built simulation environment supporting up to **8 ships**.
